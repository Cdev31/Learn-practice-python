---------UNION TYPES---------

typescript permite crear nuevos tipos apartir de tipos existentes
utilizando gran variedad de operadores.

combinacion de tipos: 

let date: string | date = ''

Nota: en funciones typescript solo permite operaciones,si las operaciones
son validas para todos los tipos.

function printId(id: number | string) {
  if (typeof id === "string") {
    // In this branch, id is of type 'string'
    console.log(id.toUpperCase());
  } else {
    // Here, id is of type 'number'
    console.log(id);
  }
}

--Sindicatos discriminados--

Los sindicatos discriminados son una forma de representar diferentes tipos de 
datos en una sola union de tipos, un ejemplo podria ser polimorfismo,podemos crear 
un tipo forma donde esten adentro las propiedades de cada tipo ya sea regtangulo,cuadrado o circulo.

type Figure = {
  figure: 'Cuadrado',
  width: 2
} | {
  figure: 'regtangle'.
  width: 4,
  height: 9
} | {
  figure: 'cicle',
  radie: 32
}

function getArea(s: Figure){
  switch(s.figure){
    case "cuadrado":
         return s.width * 4
    case "regtangle":
         return s.width * s.height     
  }
}

-------------------Mapped Type---------------

Los Mapped types son un tipo de dato que permite crear un nuevo 
tipo apartir de un tipo existente.

type OptionalReadOnly<T> = {
    readonly [P in keyof T]+?: T[P]
}

    name: string;
    age: number;
}

const partialPerson:OptionalReadOnly<Person> ={
    name: "juan carlos",
}

console.log(partialPerson)

Hay cuatro modificadores de mapeo: readonly, ?, + y -.

readonly hace que las propiedades resultantes sean de sólo lectura.
? hace que las propiedades resultantes sean opcionales.
+ indica que se deben agregar propiedades adicionales al tipo base.
- indica que se deben eliminar propiedades del tipo base.

---Anulacion de metodos.

Esta forma anula el comportamiento de un metodo heredado,lo cual hace que el metodo 
que se hereda pueda cambiar su comportamiento en la clase hija.


class Animal {
  makeSound() {
    console.log("The animal makes a sound");
  }
}

class Cat extends Animal {
  override makeSound() {
    console.log("Meow");
  }
}

const animal = new Animal();
animal.makeSound(); // "The animal makes a sound"

const cat = new Cat();
cat.makeSound(); // "Meow"

---Declaraciones de campo de solo tipo.

cuando extendemos de una clase y en la clase hija queremos cambiar el tipo
se cambiara el tipo de la clase padre en tiempo de compilacion,generando problemas,
por eso usamos declare para respetar el tipo de la clase padre.

class Base {
    name: string = "base"
}

class Derived extends Base{
    declare name: "derived"
}

const d = new Derived()
console.log(d.name)

---This type.

-This-based type guards: se utilizan para saber si un objeto

class MyClass {
  value: number;

  constructor(value: number) {
    this.value = value;
  }

  isMyClass(): this is MyClass {
    return typeof this.value === 'number';
  }
}

function exampleFunction(obj: MyClass | any) {
  if (obj.isMyClass()) {
    console.log(obj.value.toFixed(2));
  } else {
    console.log('Not a MyClass object');
  }
}

--Opciones de resolucion de modulos.

Las opciones de resolución de módulos de TypeScript son un conjunto de configuraciones que permiten a TypeScript
determinar cómo se resuelven las importaciones y referencias a otros módulos en el código. Algunas de las opciones
de resolución de módulos más comunes son:

module: esta opción especifica el sistema de módulos que se utilizará en el proyecto. Algunas opciones comunes son 
CommonJS, ES2015, AMD y System.

baseUrl: esta opción especifica la ruta base para las importaciones de módulos relativas. Por ejemplo, si se establece 
en ./src, entonces una importación relativa de ../utils se resolverá a ./src/../utils, lo que apunta a la carpeta utils 
en el nivel superior del proyecto.

paths: esta opción especifica los alias de ruta para los módulos que se utilizan en las importaciones. Por ejemplo, si se
establece una entrada @utils en paths para apuntar a la carpeta utils, entonces una importación como import { foo } from '@utils/bar'
se resolverá a ./utils/bar en el proyecto.

rootDir y outDir: estas opciones especifican los directorios de origen y destino para el proyecto, lo que ayuda a TypeScript
a determinar cómo se resuelven las importaciones de módulos.

------------------------------------Decoradores-----------------------------


Un decorador es un tipo especial de declaracion que se puede adjuntar 
a una declaracion de clase,metodo,descriptor de acceso,propiedad o parametro

Hay que diferenciar entre decorador y fabrica de decoradores,un decorador es 
una funcion que cambia las propiedades ya sea de una clase,funcion entre otras,
mientras que una fabrica de decoradores es una funcion que devuelve un decorador.


--Decorador de clase: este decorador tiene como punto de acceso a la clase en si,de ahi puede 
acceder a sus metodos,propiedades,etc.

function isMoreAge(target:Function){
    const method = target.prototype.acces

    target.prototype.acces = function(name:string,age:number){
        if(name){
            if(age <18){
                return 'Error es menor de edad'
            }
        }
        return method.apply(this,[name,age])
    }

}
@isMoreAge
class user{
    acces(name:string,age:number){
    return `puede entrar ${name} , ya que su edad es: ${age}`
    }
}
const logs = new user()
console.log(logs.acces('usuer',23))
console.log(logs.acces('user',7))

Nota: debes usar los tipos como referencia para los decoradores.

--Decorador de metodo: este decorador tiene como punto de acceso a un metodo.

function isRepit(_target:any,_property:string,descriptor:PropertyDescriptor){
    const metodoOriginal = descriptor.value

    descriptor.value = function(...args:(string | number)[]){
       if(args){
        if(args[0] == 'carlos123'){
            return 'ya existe ese nombre de usuario'
        }
       }
       return metodoOriginal
    }
}

class user{
    @isRepit
    create(name:string,age:number,role:string){
        return `bienvenido ${name}`
    }
}

const us1 = new user()
console.log(us1.create('carlos124',23,'admin'))
console.log(us1.create('carlos123',18,'normal'))


--Decorador de acceso.

Este tipo de decorador su punto de acceso es el getter y setter metodo,modificando 
ya sea logica o funcionamiento.

function convertirAMayusculas(_target: any, _propertyKey: string, descriptor: PropertyDescriptor) {
  const metodoOriginal = descriptor.set;

  descriptor.set = function (valor: string) {
    const valorEnMayusculas = valor.toUpperCase();
    metodoOriginal.call(this, valorEnMayusculas);
  };

  return descriptor;
}

class Persona {
  private _nombre: string;

  @convertirAMayusculas
  set nombre(nombre: string) {
    this._nombre = nombre;
  }

  get nombre() {
    return this._nombre;
  }
}

const persona = new Persona();
persona.nombre = 'Juan'; 
console.log(persona.nombre);
