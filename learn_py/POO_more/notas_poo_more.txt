----------------------Decoradores-----------------------

Los decoradores son funciones los cuales se ejecutan antes ya sea de una funcion,
clase,metodo,etc. Esta misma sirve para agregarle o cambia el comportamiento del 
elemento a decorar.

-Decorador de clase: Estos se utilizan para modificar el comportamiento de una 
clase.

def protectedProperties():
    def superAutos(cls):
        class superAuto(cls):
            attrProperty =[]

            def __setattr__(self, name,value):
                print(name)
                self.attrProperty.append(value)
                if name.startswith('__') or name.startswith(f'_{cls.__name__}'):
                    raise AttributeError("No puedes sobreesribir la propiedad privada")
                else:
                    return super().__setattr__(name, value)

           
        return superAuto
    return superAutos

--Decorador de metodo o funcion: Estos decoradores se aplican a las funciones o 
metodos de clase.

def rmSensitiveData(func):
    def wrapper(self,id):
        user = func(self,id)
        if user:
            dataUser = user.copy()
            del dataUser['email']
            del dataUser['password']
            return dataUser
        else:
            return False
    return wrapper  

@rmSensitiveData
    def findUser(self,id):
        for user in self.users:
            if user['id'] == id:
                return user
        return False   
        

-------------------Orientado a objetos------------------

Existen 4 pilares de la POO estos son:

-Abtraccion: es el proceso de identificar y definir los atributos y 
metodos esenciales de un objeto(caracteristicas y comportamientos) y 
luego concentrarse en eso e ignorar el resto.

-Encapsulamiento: el Encapsulamiento es la tecnica de ocultar la 
complejidad interna de un objeto,permitiendo que solo se acceda a el 
a traves de una interfaz publica bien definida.

-Herencia: la herencia es la capacidad de una clase de heredar los 
atributos y metodos de otra clase.

-Polimorfismo: el polimorfismo se refiere a la capacidad de un objeto 
para tomar muchas formas.


--Creacion de clases(Abstraccion,polimorfismo y herencia).

Par crear una clase se utiliza la palabra reservada class name():,se puede
omitir los parentesis ya que estos se usan para heredar o acceder a el contructor.

Existen propiedades y metodos,estos definen el comportamiento de la clase(objeto),
es importante saber que se pueden tener propiedades por defecto o pedir que cuando se 
cree un objeto(instancie) se fuerze agregar las propiedades que yo pida,a eso se le 
llama metodo constructor,en total de cuentas los metodos son funciones y las propiedades 
son las variables.

Existen 2 tipos de metodos y 2 tipos de clase.

metodo normal y de clase:un metodo normal es aquel que se utiliza instanciado la clase,mientras 
que el metodo de clase infiere directamente con la clase internamente.

Clase normal y clase Abstracta: una clase Abstracta es una clase la cual no puede ser instanciada 
directamente,mientras que la normal si.

---------------------Dunders Methods------------------------

Los dunders methods son metodo especiales que definen el comportamiento 
de los objetos en python.

--Dunders de clase:

__init__: se utiliza para inicializar una instancia de clase(constructor)

__str__: se utiliza para definir la representacion de cadena de una instancia
de clase.

__repr__:se utiliza para definir la representacion de cadena oficial de una 
instancia de clase.

__eq__: se utiliza para comparar 2 instancias de clase.

__new__:este metodo se utiliza siempre en la instanciacion de un objeto, ejecutandose 
antes de instancias un objeto

__setattr__(self, name, value): Este método se llama cuando se establece un valor para un atributo del objeto. Se utiliza para controlar el comportamiento de la asignación de atributos.

__getattr__(self, name): Este método se llama cuando se intenta acceder a un atributo que no existe en el objeto. Se puede utilizar para crear atributos dinámicamente.

__delattr__(self, name): Este método se llama cuando se intenta eliminar un atributo del objeto utilizando la palabra clave del.

__len__(self): Este método se utiliza para obtener la longitud del objeto, y se llama cuando se utiliza la función len() sobre el objeto.

__contains__(self, item): Este método se llama cuando se utiliza la palabra clave in para determinar si un elemento se encuentra en el objeto.

__add__(self, other): Este método se llama cuando se utiliza el operador + para sumar dos objetos.

__sub__(self, other): Este método se llama cuando se utiliza el operador - para restar dos objetos.

__mul__(self, other): Este método se llama cuando se utiliza el operador * para multiplicar dos objetos.

__truediv__(self, other): Este método se llama cuando se utiliza el operador / para dividir dos objetos.

__ne__(self, other): Este método se llama cuando se utiliza el operador != para comparar dos objetos.

__lt__(self, other): Este método se llama cuando se utiliza el operador < para comparar dos objetos.

__gt__(self, other): Este método se llama cuando se utiliza el operador > para comparar dos objetos.

__le__(self, other): Este método se llama cuando se utiliza el operador <= para comparar dos objetos.

__ge__(self, other): Este método se llama cuando se utiliza el operador >= para comparar dos objetos.

__del__: este metodo se llama cuando el objeto es eliminado con del.
