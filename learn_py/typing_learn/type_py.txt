-Wheel: este tiene mejor adaptacion con pip.

organizacion.

Listas, diccionarios y tuplas.

Las listas,diccionarios y tuplas son formas de manipular
lo que es la memoria,estas son muy utiles en ciertos procesos y
problemas.

Listas: o tambien llamados arrays, es una estructura el cual
se basa en elementos ordenados los cuales pueden ser identificados
con un indice que comienze desde el cero.

ejemplo:
myList = [1,'hello',True, [newList:{}]]

metodos de manipulacion de listas:

append(): Agrega un elemento al final de la lista.
extend(): Agrega varios elementos al final de la lista.
insert(): Inserta un elemento en una posición específica de la lista.
remove(): Elimina un elemento específico de la lista.
pop(): Elimina el último elemento de la lista o el elemento en una posición específica.
index(): Devuelve la posición de un elemento específico en la lista.
count(): Devuelve la cantidad de veces que aparece un elemento específico en la lista.
sort(): Ordena los elementos de la lista de manera ascendente o descendente.
reverse(): Invierte el orden de los elementos de la lista.
clear(): Elimina todos los elementos de la lista.
copy(): Crea una copia superficial de la lista.
deepcopy() : Crea una copia profunda de la lista.

Diccionarios: son estructuras clave valor, desordenadas los cuales
accedes a ellos, por la mismca clave.

ejemplo:
myDicc = {
    'clave': valor,
     'clave': []
     }

metodos de manipulacion de diccionarios:

get(): Devuelve el valor de una clave específica en el diccionario, o un valor predeterminado si la clave no existe.
items(): Devuelve una lista de los pares clave-valor del diccionario.
keys(): Devuelve una lista de las claves del diccionario.
values(): Devuelve una lista de los valores del diccionario.
pop(): Elimina un par clave-valor específico del diccionario y devuelve su valor.
popitem(): Elimina un par clave-valor al azar del diccionario y devuelve su valor.
clear(): Elimina todos los pares clave-valor del diccionario.
update(): Actualiza el diccionario con los pares clave-valor de otro diccionario o de un objeto iterable.
setdefault(): Establece el valor de una clave específica en el diccionario si no existe.
copy(): Crea una copia del diccionario.
fromkeys(keys,value): Crea un nuevo diccionario con las claves especificadas y el valor especificado.
len(): devuelve la cantidad de pares clave-valor en el diccionario.

Tuplas: son como las listas estan metidas entre '()' pero son inmutables
lo que hace que existan menos metodos para su manipulacion.

ejemplo: 
myTuple = (1,2,3,4)

algunos metodos que pueden ser usados en tuplas:

count(): Devuelve la cantidad de veces que aparece un elemento específico en la tupla.
index(): Devuelve el índice de la primera aparición de un elemento específico en la tupla.
len(): devuelve la cantidad de elementos en la tupla.

Tipo Any y object

El tipo Any es un tipo el cual evalua en cualquier otro tipo,ya sea null,none,str
entre otros,mientras que object es el tipo base de python,este si es usado evalua
el tipo como un tipo cualquiera, que sea exclusivamente un objeto de python.

Ejemplo:

varName: Any = 12 #acepta cualquier valor
varName: object = {} || def # acepta nada mas objetos de python.

Para usar Any se usa typing.

---------------Type self-----------------

Este tipo hace referencia a la clase en si,puede ser de mucha ayuda con el tipo Type.

class Rectangle:
    def __init__(self, width: int, height: int):
        self.width = width
        self.height = height

    def area(self) -> int:
        return self.width * self.height

    @classmethod
    def square(cls: Type[Rectangle], side: int) -> 'Rectangle':
        return cls(side, side)

print(square.area()) # 100

------TypeVar,TypeVarTuple y Generic Type-----------

Primero hay que diferenciar 2 conceptos,tipos genericos y variables de tipo 
genericos.

Variables de tipo generico: estas son abstracciones de cierta conceptualizacion,
estas se definen y en tiempo de compilacion,cuando una funcion recibe un parametro de 
tipo generico y se manda el tipo:

T = TypeVar('T')

   def prob(arg: T) -> T:
      return T 

   print(prob(2))  

La variable de tipo generico es T ya que en la llamada a la funcion se paso el 
parametro 2.

Tipo generico: Este tipo recibe cualquier valor, y se usa TypeVar para crearlo.

Generic: este sirve para crear clases y funciones genericas.

T = TypeVar("T")

class Inventory(Generic[T]):
    def __init__(self, items: List[T]):
        self._items = items

    def add_item(self, item: T):
        self._items.append(item)

    def get_items(self) -> List[T]:
        return self._items

inventory = Inventory([1, 2, 3, 4, 5])
inventory.add_item(6)
print(inventory.get_items())

TypeVarTuple: es como TypeVar solo que este permite definir varias 
variables de tipo generico

T = TypeVar('T')
S = TypeVar('S')

def foo(arg1: T, arg2: S) -> Tuple[T, S]:
    return arg1, arg2

print(foo(1, 'a')) # (1, 'a')
print(foo('b', 2)) # ('b', 2)

------------Protocol and Mapping Type----------------

El tipo Protocol es como una interfaz en otros lenguajes de programacion sirve para
firmar un contrato de los valores a contener.

El tipo Mapping representa una estructura de datos mapeables, de tipo clave valor,
verificando si estos son un diccionario.
class Book(Protocol):
    id: int
    title: str
    stock: int
    age: int

   def process_book(book: Mapping[str,Book]) -> None:
      print(book['id'], book['title'], book['stock'], book['age'])

   book_dict: Dict[str,int] = {
      'id': 1,
      'title': 'The Great Gatsby',
      'stock': 10,
      'age':12
    }

   process_book(book_dict)
