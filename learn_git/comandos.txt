---------UNION TYPES---------

typescript permite crear nuevos tipos apartir de tipos existentes
utilizando gran variedad de operadores.

combinacion de tipos: 

let date: string | date = ''

Nota: en funciones typescript solo permite operaciones,si las operaciones
son validas para todos los tipos.

function printId(id: number | string) {
  if (typeof id === "string") {
    // In this branch, id is of type 'string'
    console.log(id.toUpperCase());
  } else {
    // Here, id is of type 'number'
    console.log(id);
  }
}

------------NARROWING---------

Es un proceso en typescript donde el compilador restringe el tipo 
de una variable basado en la informacion disponible en 
tiempo de compilacion.

let x: number | string =4;
if (typeof x === 'number'){
  x='hello'
}


-Estrechamiento de veracidad: esta es un tipo de narrowing donde el compilador 
restringe el tipo de una variable basado en una evalucacion boleana, este puede ser mas util con 
los valores null y undefined

-Estrechamiento con in: este verifica si existe una clave en un objeto.

const obj = {a: 1, b: 2}
if ('a' in obj){
  //retorna true o false
}

-estrechamiento por instanceof: estte verifica que un objeto sea instancia de una clase o prototipo.

NOTA: 'Typescript puede inferir en el tipo de una variable respecto a la primera declaracion de tipo de la variable'

-Predicado de tipos: en typescript son funciones que toman un tipo 
como argumento y devuelven un valor booleano que indica si el tipo 
cumple con cierts condiciones.Se utilizan para escribir tipos personalizados que 
se ajustan a una determinada forma o comportamiento.

type IsNumber = (x: any) => x is number;
const isNumber: IsNumber = (x) => typeof x === 'number';

let x = 42;
if (isNumber(x)) {
  console.log(x.toFixed(2)); // 42.00
}


--Sindicatos discriminados--

Los sindicatos discriminados son una forma de representar diferentes tipos de 
datos en una sola union de tipos, un ejemplo podria ser polimorfismo,podemos crear 
un tipo forma donde esten adentro las propiedades de cada tipo ya sea regtangulo,cuadrado o circulo.

type Figure = {
  figure: 'Cuadrado',
  width: 2
} | {
  figure: 'regtangle'.
  width: 4,
  height: 9
} | {
  figure: 'cicle',
  radie: 32
}

function getArea(s: Figure){
  switch(s.figure){
    case "cuadrado":
         return s.width * 4
    case "regtangle":
         return s.width * s.height     
  }
}

---------------------Type KeyOf-------------------

El tipo keyOf toma un tipo de objeto y produce una cadena o union literal numerica 
de sus claves.


interface User {
    name: string
    age: number
    email: string
}

type UserKeys = keyof User

const user: User = {
    name: 'kalet',
    age:23,
    email: 'kal@gmail.com',
}

function isValidAge(user:User, key: UserKeys,value: any):boolean{
    return user[key] === value
}

console.log(isValidAge(user,'age',30))

--Restricciones de tipo condicional.

--Tipos distributivos condicionales.

Se dice que son distribuidos cuando la condicion se aplica a cada 
miembro de una union de tipos.

type MyType<T> = T extends string ? number : boolean;

type Result = MyType<"hello" | true | 42>; 
// Result es (number | boolean) | boolean | boolean

-------------------Mapped Type---------------

Los Mapped types son un tipo de dato que permite crear un nuevo 
tipo apartir de un tipo existente.

type OptionalReadOnly<T> = {
    readonly [P in keyof T]+?: T[P]
}

interface Person {
    name: string;
    age: number;
}

const partialPerson:OptionalReadOnly<Person> ={
    name: "juan carlos",
}

console.log(partialPerson)

Hay cuatro modificadores de mapeo: readonly, ?, + y -.

readonly hace que las propiedades resultantes sean de sólo lectura.
? hace que las propiedades resultantes sean opcionales.
+ indica que se deben agregar propiedades adicionales al tipo base.
- indica que se deben eliminar propiedades del tipo base.

Uppercase<StringType>

Lowercase<StringType>
